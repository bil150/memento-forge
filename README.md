# MementoForge

Aide-mémoires HTML imprimables (commandes Linux, Windows, Dev & Applicatifs), au format A4 paysage.

## Contenu

- [`index.html`](index.html) — page d'accueil avec navigation vers les 3 mémentos
- `memento-linux.html` — commandes GNU/Linux (système, réseau, permissions...)
- `memento-windows.html` — PowerShell, cmd, administration Windows
- `memento-applicatifs.html` — Git, Docker, Claude, API, bases de données, CI/CD...

## Utilisation

Ouvrir `index.html` dans un navigateur. Chaque mémento propose un réglage d'échelle
et de nombre de colonnes (avec bouton **Ajuster auto**) pour que le contenu tienne
sur une page A4. À l'impression : orientation **Paysage**, marges **Aucune**,
échelle **100 %**, et activer les graphiques d'arrière-plan pour conserver les couleurs.

## Structure

```
index.html
memento-*.html
css/memento.css   → styles partagés par toutes les pages
```
